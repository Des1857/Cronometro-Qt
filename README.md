# Cronómetro

Aplicación de cronómetro de escritorio desarrollada en **C++** utilizando **Qt 6**.

## Descargar

[Descargar Cronómetro 1.0.0 para Windows](https://github.com/Des1857/Cronometro-Qt/releases/tag/v1.0.0)

La versión para Windows se distribuye como un archivo ZIP portable. No requiere instalación.

## Características

- Cronómetro con precisión de milisegundos.
- Iniciar y pausar el cronómetro.
- Reiniciar el cronómetro.
- Registro de vueltas.
- Tiempo total y tiempo individual de cada vuelta.
- Tema claro y oscuro.
- Configuración del tamaño de los dígitos.
- Configuración guardada entre ejecuciones.
- Interfaz gráfica desarrollada con Qt 6.
- Ejecutable portable para Windows.

## Requisitos

Para utilizar la versión compilada para Windows:

- Windows 10 o superior.
- No es necesario instalar Qt ni C++.

Para compilar el proyecto desde el código fuente:

- CMake 3.21 o superior.
- Compilador compatible con C++20.
- Qt 6 con el módulo Widgets.
- Ninja.

## Compilar

Clonar el repositorio:

```bash
git clone https://github.com/Des1857/Cronometro-Qt.git
cd Cronometro-Qt
```
